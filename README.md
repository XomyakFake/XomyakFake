## Projects I've made

### 🎬 [Movies Collection Manager](https://github.com/XomyakFake/itmo-prog-labs/tree/00ca43a9da268e5b0048f76b7afcef23e7ae5651/proglab8)
Client-server application for managing a collection of movies: authorization and registration, CRUD operations, filtering, sorting, and a visual JavaFX client with localization in 4 languages.

**Tech:** `Java` · `Swing` · `JDBC` · `PostgreSQL` · `Gradle`

### 📊 [System Monitor](https://github.com/XomyakFake/system-monitor)
Linux desktop system monitor: CPU, memory and network usage, a live list of the most active processes with search, sorting and signal sending (SIGTERM/SIGKILL), plus history charts. A separate worker thread reads `/proc`, so the GUI never blocks.

**Tech:** `C++17` · `Qt 6` · `CMake` · `Multithreading` · `Linux /proc`
