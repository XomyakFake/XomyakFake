# About Me
Hi! I'm Anton Efimov. Bachelor's student in System & Application Software @ ITMO University.

**A few projects I've made:**

- 🎬 [`movies-collection-manager`](https://github.com/XomyakFake/itmo-prog-labs/tree/00ca43a9da268e5b0048f76b7afcef23e7ae5651/proglab8) is a client-server application for managing a collection of movies, with registration and authorization, CRUD operations, filtering and sorting. Built with Java, a Swing GUI localized in 4 languages, JDBC with PostgreSQL, and Gradle.
- 📊 [`system-monitor`](https://github.com/XomyakFake/system-monitor) is a Linux desktop monitor in C++17 and Qt 6 that shows CPU, memory and network usage, a live list of the most active processes with search, sorting and SIGTERM/SIGKILL, and history charts. A separate worker thread reads `/proc`, so the GUI never blocks.
